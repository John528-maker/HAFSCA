# 무엇인가?

**다항 회귀**는 더 풍부한 특징 맵 $\phi(x)=(T_0(x),\ldots,T_d(x))^{\top}$을 쓰는 선형 회귀입니다. 차수 $d$는 $p=d+1$의 손잡이이지, 다른 종류의 손실이 아닙니다.

# 왜 중요한가?

과적합·이중 하강 실험은 이미 이 다항식을 맞춥니다. 기울기를 만나기 *전에* 손잡이의 이름을 알면, 구불구불한 곡선이 새 알고리즘처럼 보이지 않습니다.

# 직관

차수 1은 방금 드래그한 직선입니다. 차수 3은 삼차 참값을 따라갈 수 있습니다. 차수 12는 노이즈를 붙잡을 수 있습니다. 같은 solver, $X$의 열만 늘어납니다.

# 수학

이 사이트는 $[-1,1]$에서 Chebyshev $T_k$와 arcsine 표본 $x$를 써서 고차수도 수치적으로 버팁니다. 잔차와 손실은 그대로입니다: $\mathbf r=X\theta-\mathbf y$, $J=\frac1n\lVert\mathbf r\rVert_2^2$.

# 요약

복잡도는 $\phi$의 폭이지, 오차의 새 정의가 아닙니다.
