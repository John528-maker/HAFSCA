# 무엇인가?

**과적합**은 학습 오차는 계속 내려가는데 보지 못한 $x$의 오차는 올라가는 상황입니다. 여분 용량으로 노이즈를 외웁니다.

# 왜 중요한가?

더 작은 학습 MSE가 더 좋은 모델의 증명서는 아닙니다. 학습이 들여다보지 못한 검사가 필요합니다. 여기선 참 삼차식 $f$에 대한 오차이고, 노이즈 레이블 오차는 두 번째 곡선입니다.

# 직관

삼차 참값에 노이즈를 더하면 차수 $3$–$5$가 **평탄 구간**인 경우가 많습니다. 실험은 “최적이 3인 이유는 진짜 차수가 3이기 때문”이라고 **말하지 않습니다**. 데이터가 유일한 승자를 지지하지 않습니다.

# 실험

복잡도 상한은 차수 **$12$**입니다. 이 문단이 아니라 코드에 있습니다. 어떤 시드(1을 시도)는 **깨끗한 최적 구간이 없고**, 안내 문구가 그렇게 말합니다.

두 번째 실험은 학습 집합을 $M$번 다시 뽑아 적합 곡선을 펼칩니다. 기댓값에서 테스트 오차는 노이즈 $+$ 편향$^2$ $+$ 분산입니다. 누적 막대는 나누기 $M-1$과 보정한 편향$^2$를 쓰며, **홀드아웃 테스트 MSE가 아닙니다**.
