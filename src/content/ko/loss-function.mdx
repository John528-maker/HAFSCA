# 무엇인가?

**손실**은 학습점에서 모델이 얼마나 틀린지를 하나의 숫자로 만든 것입니다. 이 과정은 평균 제곱 오차를 씁니다.

$$
J(\theta)=\frac{1}{n}\sum_{i=1}^{n}(\hat y_i-y_i)^{2}.
$$

앞에 $\tfrac12$는 **없습니다**. 차트 $y$축이 바로 이 $J$입니다.

# 왜 중요한가?

손실이 없으면 “더 좋은 적합”은 느낌입니다. $J$가 있으면 도함수, 기울기, 경사 하강법은 모두 이 숫자를 줄이는 도구가 됩니다.

# 직관

잔차 $\hat y_i-y_i$는 부호 있는 빗나감입니다. 제곱하면 부호를 잊고 큰 오차를 더 벌합니다. $n$으로 나누면 점을 늘려도 스케일이 비슷합니다.

# 수학

행렬로는 $J(\theta)=\frac1n\lVert X\theta-y\rVert_2^2$이고, 미분하면 $\nabla J=\frac2n X^{\top}(X\theta-y)$입니다. 그 $2$ 때문에 절편+기울기 모델의 헤시안 원소 $H_{22}$는 $1$이 아니라 $2$입니다.

# 요약

손실은 이 사이트 오차 차트의 이름 붙은 $y$축입니다.
