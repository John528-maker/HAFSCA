# 무엇인가?

**모델**은 입력 $x$와 **매개변수** $\theta$에 따라 출력이 정해지는 함수 $f(x;\theta)$입니다. 식을 다시 쓰지 않고 $\theta$만 바꾸면 함수가 바뀝니다.

# 왜 중요한가?

이후 수업은 모두 예제에 맞도록 $\theta$를 고르는 이야기입니다. “모델 = 매개변수를 가진 함수”가 흐리면 손실, 기울기, 과적합이 따로 노는 용어처럼 보입니다.

# 직관

$f(x;\theta)=\theta_0+\theta_1 x$를 생각해 보세요. *모양*은 직선이고, *어느* 직선인지는 $\theta$가 정합니다. $\theta_1$을 움직이면 기울기가 변합니다. 데이터도, 함수 가족도 그대로이고 매개변수만 변합니다.

# 수학

$\theta\in\mathbb{R}^{p}$로 씁니다. 차수 $d$ 다항식이면 $p=d+1$입니다. 특징 맵 $x\mapsto \phi(x)$는 고정이고, 학습은 $\theta$만 움직입니다.

# 요약

기억할 것: **데이터가 들어가고, 매개변수가 들어가고, 예측이 나옵니다.** 나머지 과정은 그 매개변수를 어떻게 고르느냐입니다.
