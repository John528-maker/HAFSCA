# 무엇인가?

**일반화**는 적합이 쓰지 못한 $x$에서의 오차입니다. 학습 MSE는 줄인 숫자입니다. 질문이 아닙니다.

# 왜 중요한가?

이후 차트는 모두 학습/테스트로 점을 나눕니다. 분할은 `dataset.ts`에 있습니다. 시드 있는 셔플 뒤, 과적합 실험은 80/20, 대표 실험은 40/460입니다.

# 직관

학습 오차만 보면 노이즈를 외운 모델이 완벽해 보입니다. 테스트 점이 감사입니다.

# 수학

대표 실험의 주 테스트 MSE는 노이즈 레이블이 아니라 참 $f$에 대한 값입니다. 너무 작은 테스트 집합($n_{\mathrm{test}}<160$)은 보정에서 double-descent 판정을 거짓말하게 만들었습니다. 과적합 U곡선은 테스트가 10개뿐이라 평탄 구간이 유일한 승자가 아닙니다.

# 요약

질문이 되는 것은 보지 못한 오차입니다. 학습 오차는 다른 질문에 답하려 한 도구입니다.
